# Temporary 이미지 리소스

현재 게임에 사용하는 임시 그래픽 PNG 50개를 보관한다.
게임은 실행할 때 저장된 PNG를 한 번 불러오며, 실행 중 이미지 파일을 생성하지 않는다.
카메라 이동, 충돌 영역, 전투 로직은 기존과 같다.

- 배경을 레이어별로 나눠 기존 시차 스크롤을 유지한다.
- 플레이어 걷기와 횃불은 각각 8프레임을 사용한다.
- 총은 별도 이미지로 회전시켜 마우스 조준과 반동을 표현한다.
- 적은 좌우 방향 및 피격 색상, 출구는 잠금·개방 이미지를 사용한다.
- PNG는 표시 크기의 2배 해상도이며 투명 배경을 사용한다. `sky.png`, `ground.png`는 불투명하다.

같은 파일명의 PNG를 수정하거나 교체한 뒤 다시 빌드하면 게임에 반영된다.
이미지 전체가 정해진 표시 크기에 맞춰 그려지므로 기존 여백과 중심점을 유지하는 것이 좋다.
빌드와 배포 시 `resource/Temporary/*.png`를 실행 파일 옆의 같은 경로에 복사한다.

기존 도형 그래픽으로 다시 내보내려면 저장소 루트에서 다음 명령을 실행한다.
이 명령은 이 폴더의 PNG를 덮어쓰므로 직접 수정한 이미지는 먼저 보관한다.
게임 빌드나 실행 시 자동으로 실행되지는 않는다.

```powershell
dotnet run --project .\tools\TemporaryAssets -- .\resource\Temporary
```

전체 파일 분류는 [리소스 목록](../resource_list.md)에 있다.
