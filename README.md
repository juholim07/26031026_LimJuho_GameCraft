# 기말과제 
- 이름 : 임주호
- 게임이름 : Devil on bullet

## 실행

```powershell
dotnet run --project .\DevilonBullet
```

Enter로 도전을 시작하고 F1로 도움말을 연다.

배경·발판·캐릭터 등 고정 그래픽은 [`resource/Temporary`](resource/Temporary/README.md)의 PNG를
실행 시 한 번 불러온다. 이미지 파일은 빌드 및 배포 결과에 자동으로 복사된다.

| 조작 | 동작 |
| --- | --- |
| A / D, 좌우 방향키 | 이동 |
| Space / W, 위 방향키 | 점프 |
| 마우스 이동 / 좌클릭 | 조준 / 사격 |
| 우클릭 / Shift | 탄환 1발을 소모해 마우스 방향으로 대시 |
| 휠 아래 / 위 | 강화 선택 / 취소 |
| Q | 과열 100%일 때 남은 탄환 전탄격발 |
| Esc | 일시정지 / 재개 |
| Alt + Enter | 전체화면 전환 |

강화는 장전당 1회, 최대 3발을 소모한다. 잔탄이 1~2발이어도 사용할 수 있으며 이때는 남은 탄환을 모두 소모한다. 자동 재장전 후 강화권이 복구된다.
저격탄 강화는 즉발 관통 레이저, 산탄 강화는 2연사, 폭발탄 강화는 짧은 거리에서 터지는 넓은 폭발이다.
대시 또는 사격으로 마지막 탄환을 소모하면 자동으로 재장전한다.
일반 사격 속도는 초당 1.3회(약 0.769초 간격)이며, 이 간격에 0.2초의 사격 후딜이 포함된다. 후딜 중에도 이동·점프·대시가 가능하다. 강화 공격과 산탄 강화 2연사의 속도는 별도로 유지한다.
