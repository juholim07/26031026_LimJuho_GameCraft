# 데빌 온 불릿 게임 기획서

- 게임 : 데빌 온 불릿
- 작성자 : 임주호

## 개요

- 장르 : 2d 플랫포머
- 게임 소개 : 악마들이 자신의 영지와 순위를 걸고 경쟁하는 랭킹 쇼를 배경으로, 갓 태어난 총의 악마 ‘슈케트’가 다른 악마의 영지에 도전하는 게임이다. 플레이어는 슈케트를 조작해 지형을 넘고, 서로 다른 탄환이 장전된 6발 리볼버로 적을 상대한다. Unity를 사용하지 않는 C# 기반 게임으로 제작하며, 맵 2개로 하나의 도전을 구성한다.
- 핵심 재미 한줄 요약 : 정해진 순서의 탄환을 빠르게 비우면서 상황에 맞게 강화와 사격을 이어 가고, 달라지는 전투 상황에 즉각 대처하는 숙련의 재미.

## 게임 진행

- **맵 구성** : 한 악마의 영지를 입구와 결투장, 총 2개의 짧은 맵으로 구성한다. 입구 맵은 평지와 낮은 발판으로 이루어지며, 접근해 공격하는 근접 적과 거리를 두고 탄환을 쏘는 원거리 적을 배치한다. 결투장 맵은 점프로 공격을 피하거나 거리를 벌릴 수 있는 발판을 두고, 체력이 높은 지배 악마와 소수의 일반 적을 함께 배치한다. 지배 악마는 접근 공격과 예고 후 사격을 반복한다.

- **진행과 클리어** : 입구에서 적을 모두 처치하면 결투장으로 가는 출구가 열린다. 결투장에서 지배 악마와 남은 적을 모두 처치하면 도전 성공으로 처리한다. 결과 화면에는 랭킹 쇼의 승리 안내와 처치 수, 클리어 시간, 남은 체력을 표시한다. 체력이 0이 되면 도전에 실패하며, 현재 맵의 처음부터 다시 도전할 수 있다.

- **6발 리볼버** : 저격탄·분열탄·폭발탄을 각 2발씩 섞어 장전하는 구성을 기본안으로 한다. 한 번 장전된 탄환의 순서는 바꿀 수 없으며, 사격할 때마다 현재 선두 탄환을 소모하고 다음 탄환으로 넘어간다. 원하는 탄종으로 즉시 교체하는 기능은 없다. 화면에는 남은 탄환의 순서와 현재 선두 탄환을 표시한다.

- **탄종별 활용** : 저격탄은 멀리 있는 적을 정확히 공격하기 좋지만 여러 방향에서 접근하는 적을 한꺼번에 처리하기 어렵다. 분열탄은 여러 탄환이 퍼져 나가 가까운 적에게 집중적으로 맞히기 좋지만 거리가 멀어지면 화력이 분산된다. 폭발탄은 착탄 지점 주변을 공격해 밀집한 적에게 유리하지만 흩어진 적에게는 범위 공격의 이점을 살리기 어렵다.

- **일반 사격 속도** : 초당 1.3회, 약 0.769초 간격으로 발사한다. 발사 직후 0.2초 동안 후딜과 반동 복귀를 적용하며 이 시간은 발사 간격에 포함한다. 이동·점프·대시는 후딜 중에도 가능하다. 강화 공격의 발사 간격과 강화 산탄 2연사 간격은 별도로 유지한다.

- **선두 탄환 강화** : 마우스 휠 아래로 현재 선두 탄환의 강화 공격을 선택하고, 휠 위로 선택을 취소한다. 강화 사격은 장전당 1회, 최대 3발을 소모한다. 잔탄이 1~2발이어도 강화할 수 있으며 남은 탄환을 모두 소모한다. 저격탄 강화는 조준 방향의 적들을 즉시 관통하는 레이저, 산탄 강화는 2연속 집중 사격, 폭발탄 강화는 총구에서 90px 이동 후 반경 190px의 넓은 폭발이다. 강화 격발마다 0.32초 동안 게임 속도를 34%로 낮춰 타격감을 준다. 강화권은 자동 재장전이 끝나면 복구된다.

- **대시** : 우클릭 또는 Shift로 마우스가 가리키는 방향으로 대시한다. 수평·수직·대각선으로 이동하며 시작 순간의 방향을 유지한다. 현재 선두 탄환을 1발 소모하고 공격은 발생하지 않는다. 마지막 탄환을 대시에 사용해도 자동 재장전이 시작되며, 재장전 중에는 대시할 수 없다.

- **자동 재장전과 전투 흐름** : 6발을 모두 소모하면 짧은 자동 재장전이 시작된다. 탄환이 남아 있을 때는 재장전할 수 없으며, 별도의 재장전 키도 없다. 재장전 중에는 이동과 점프가 가능하지만 사격은 불가능하다. 플레이어는 남은 탄환을 빠르게 비워 다음 장전을 앞당기거나, 유리한 탄환을 적에게 맞힐 기회를 잡는 식으로 전투를 이어 간다. 마지막 탄환을 쏘기 전에 적과의 거리와 피할 공간을 살피는 것도 중요하다.

- **구현 범위** : 이동·점프·마우스 조준·사격·선두 탄환 강화·자동 재장전과 맵 2개의 전투 및 결과 화면을 구현한다. 전탄격발과 과열 시스템은 이번 과제 범위에서 제외한다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| A / D 또는 좌우 방향키 | 좌우 이동 |
| Space / W 또는 위 방향키 | 점프 |
| 마우스 이동 | 조준 방향 변경 |
| 마우스 좌클릭 | 현재 선두 탄환 발사. 강화가 선택되어 있으면 강화 공격 실행 |
| 마우스 휠 아래 1회 | 현재 선두 탄환의 강화 공격 선택 |
| 마우스 휠 위 | 강화 선택 취소 및 일반 사격으로 복귀 |
| 마우스 우클릭 / Shift | 탄환 1발을 소모해 마우스 방향으로 대시 |

- 강화 공격을 실행하면 선택 상태가 해제되어 다음 탄환은 일반 사격으로 돌아간다. 강화 사용 횟수가 남아 있을 때만 강화 선택이 가능하다.
- 재장전은 모든 탄환을 소모한 뒤 자동으로 진행된다.
